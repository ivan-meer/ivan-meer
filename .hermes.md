# Ivan Meer Portfolio — Project Rules for Hermes

## Tech Stack
- Vanilla HTML + CSS + JS — no frameworks
- Dark theme: OKLCH color space
- Base href: `/ivan-meer/`
- GitHub Pages: ivan-meer.github.io/ivan-meer/

## Journal (Blog)
- Articles are **HTML only** — NOT Markdown
- Architecture: `articles.json` (index) + `content/{id}.html` (articles)
- Scaffold new articles: `python new-article.py`
- Design components: `<figure><figcaption>`, `div.callout`, `div.stats-grid`, `<pre><code>`
- SVG illustrations: see `references/svg-illustration-patterns.md`

## Publishing
- Commit + push to `main` → GitHub Pages auto-deploys
- Always test locally before pushing: open the HTML file in browser

## Style
- Article filenames: kebab-case
- Images: WebP preferred, SVG for diagrams
- Code blocks: use `<pre><code>` with language class
